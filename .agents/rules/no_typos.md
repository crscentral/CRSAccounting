# No Typos Policy

CRITICAL INSTRUCTION: You must exercise EXTREME caution to prevent syntax errors, unbalanced brackets, missing tags, and other typos.
- Double-check all JSX and HTML tags to ensure they are properly closed.
- If you use search/replace scripts, thoroughly review the generated output for correctness.
- Never hastily push changes. Always verify that code builds correctly and that logic behaves as intended.
